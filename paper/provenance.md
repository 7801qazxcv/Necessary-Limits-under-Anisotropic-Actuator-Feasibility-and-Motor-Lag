# Provenance — every displayed number -> its on-disk artifact

All displayed numeric data values in `main.tex` arrive through `numbers.tex`,
which is generated by `build_manuscript_numbers.py` from the JSON artifacts
below. No numeric data value is transcribed by hand into the prose; the only
literal numbers outside the macros are structural (section/equation numbers,
the 60 deg / 1.5 s envelope definition, and the fixed 0.6 discriminator), each
restated in the text that defines it. Regeneration:
`python experiments/run_all_experiments.py` (add `--full` to re-run the probe
chain itself).

Known source defects, recorded rather than hidden: the Crazyflie registry's
thrust polynomial misses hover equilibrium by -16.6%, so only its shape ratio
sets `u_max`; its rising/falling motor constants are asymmetric and are
bracketed by two symmetric models in the main study; an IEEE TCSII reference is
2021 (not 2020) and an IJCAS reference is 2025 (not 2024). RPM-level quantities
are marked N/A for the force-unit registry. Two superseded result files
(`*_SUPERSEDED.json`) are kept read-only for provenance and are excluded from
all statistics.

- `author_initials.json` (2026-11-24): author given/family for all 24 cited
  entries, taken from LIVE Crossref `/works/<doi>` and arXiv Atom API responses
  (see `refs_backfill_verified.json` for the verification ledger, including the
  24/24 surname-alignment check). Consumed by `build_refs_bib.py` ->
  `author_display()` to emit `Family, Initials.` in `refs.bib`. No hand-typed
  bibliographic data; citation keys are unchanged.
